第 2 课：Emacs 基本操作

掌握键绑定、文件操作、编辑技巧和缓冲区管理

课程简介

Emacs 的强大之处在于其高度一致的键绑定系统。一旦你理解了这套系统，就能快速掌握各种操作。本课将介绍 Emacs 的核心概念和基本操作。

学习目标：掌握键绑定概念、文件操作、基本编辑和缓冲区管理，熟练使用帮助系统。

键绑定概念

Emacs 使用一套简洁的快捷键表示法，理解这套表示法是使用 Emacs 的基础。

基本表示法

符号 含义 示例 实际操作
C Ctrl 键 C-x 按住 Ctrl 再按 x
M Alt/Meta 键 M-x 按住 Alt 再按 x
S Shift 键 S-TAB 按住 Shift 再按 Tab

键序列表示法

空格分隔的多个键表示依次按下的序列：

C-x C-f    # 先按 Ctrl+x，再按 Ctrl+f
C-x C-s    # 先按 Ctrl+x，再按 Ctrl+s
M-x save-buffer  # 按 Alt+x，然后输入命令名

常用前缀键

  • C-x：扩展命令前缀，后跟具体操作键
  • C-c：模式相关命令前缀（在 Org Mode 中尤为重要）
  • M-x：输入任意命令名称
  • C-h：帮助前缀
  • C-g：取消当前操作（非常重要！）
黄金法则：如果你不知道按了什么，或者想取消正在执行的操作，按 C-g 可以取消几乎任何操作。

文件操作

打开/创建文件

要打开一个文件或创建新文件：

C-x C-f    # find-file：打开文件

Emacs 会提示你输入文件路径。输入路径后按回车即可打开。如果文件不存在，Emacs 会创建一个新缓冲区。

保存文件

保存当前文件：

C-x C-s    # save-buffer：保存当前文件
C-x C-w    # write-file：另存为

关闭文件和退出

C-x C-c    # save-buffers-kill-terminal：保存并退出 Emacs
C-x k      # kill-buffer：关闭当前缓冲区
C-x C-f    # 打开另一个文件（自动切换）
注意：退出 Emacs 前请确保已保存所有修改。如果未保存，Emacs 会提示你确认是否放弃未保存的更改。

基本编辑

光标移动

Emacs 提供了丰富的移动命令，以下是最常用的：

快捷键 功能 记忆技巧
C-f 向前移动一个字符 forward
C-b 向后移动一个字符 backward
C-n 移动到下一行 next line
C-p 移动到上一行 previous line
C-a 移动到行首 beginning of line
C-e 移动到行尾 end of line
M-f 向前移动一个词 forward word
M-b 向后移动一个词 backward word
C-v 向下翻页 scroll down (view)
M-v 向上翻页 scroll up
M-< 移动到文件开头 beginning of buffer
M-> 移动到文件末尾 end of buffer

删除操作

C-d        # 删除光标后的字符
DEL        # 删除光标前的字符（Backspace）
M-d        # 删除光标后的一个词
M-DEL      # 删除光标前的一个词
C-k        # 删除从光标到行尾的所有内容
C-S-backspace  # 删除整行

复制和粘贴

Emacs 使用"kill ring"（剪贴板环）来管理复制的内容：

C-SPC      # 开始标记区域（set-mark-command）
C-w        # 剪切选中的区域到 kill ring
M-w        # 复制选中的区域到 kill ring（不删除）
C-y        # 粘贴最近复制的内容（yank）
M-y        # 循环切换 kill ring 中的历史内容

撤销和重做

C-/        # 撤销
C-x u      # 撤销（同上）
C-g C-/    # 重做（撤销撤销）
提示：Emacs 的 kill ring 可以保存多次复制/剪切的内容。使用 M-y 可以在粘贴后循环切换不同的历史内容。

缓冲区管理

Emacs 中每个打开的文件或信息都在一个"缓冲区"（buffer）中。理解缓冲区管理是高效使用 Emacs 的关键。

常用缓冲区操作

C-x b      # 切换到另一个缓冲区
C-x C-b    # 列出所有缓冲区
C-x k      # 关闭（销毁）一个缓冲区
C-x LEFT   # 切换到上一个缓冲区
C-x RIGHT  # 切换到下一个缓冲区

缓冲区列表操作

在缓冲区列表（C-x C-b）中，可以使用以下快捷键：

d          # 标记为删除
s          # 标记为保存
u          # 取消标记
x          # 执行标记的操作
~          # 标记为只读
缓冲区 vs 文件：不是所有缓冲区都对应文件。例如，*Messages* 缓冲区显示 Emacs 的消息日志，*scratch* 是一个临时的笔记缓冲区。

帮助系统

Emacs 拥有强大的内置帮助系统，是学习 Emacs 的最佳工具。

基本帮助命令

C-h C-h    # 显示帮助菜单
C-h k      # 描述一个按键绑定的功能
C-h f      # 描述一个函数
C-h v      # 描述一个变量
C-h m      # 显示当前模式的信息
C-h a      # 搜索与关键词匹配的命令
C-h t      # 启动内置教程

实用示例

如果你忘记了某个快捷键的功能：

  1. 按 C-h k
  2. 然后按你要查询的快捷键（如 C-x C-s）
  3. Emacs 会显示该快捷键的功能说明

如果你知道功能但不知道快捷键：

  1. 按 C-h a（Apropos）
  2. 输入功能关键词（如 "save"）
  3. Emacs 会列出所有匹配的命令
推荐：首次使用 Emacs 的用户强烈建议按 C-h t 完成内置教程。这个教程大约需要 30 分钟，但能让你快速熟悉 Emacs 的基本操作。

迷你缓冲区

Emacs 底部的小型输入区域称为"迷你缓冲区"（minibuffer），用于输入命令参数、文件名等。

迷你缓冲区操作

TAB        # 自动补全
M-n        # 查看下一个历史记录
M-p        # 查看上一个历史记录
C-g        # 取消输入
RET        # 确认输入

使用 M-x 执行命令

几乎所有 Emacs 命令都可以通过 M-x 执行：

M-x save-buffer    # 执行保存命令
M-x org-mode       # 切换到 Org Mode
M-x describe-key   # 等同于 C-h k
M-x list-buffers   # 等同于 C-x C-b
提示：使用 M-x 时支持自动补全。输入部分命令名后按 TAB 可以补全，按 TAB 两次可以列出所有匹配项。

搜索和替换

搜索

C-s        # 增量搜索（向下）
C-r        # 增量搜索（向上）
C-M-s      # 正则表达式搜索（向下）
C-M-r      # 正则表达式搜索（向上）

在增量搜索中：

C-s        # 跳转到下一个匹配
C-r        # 跳转到上一个匹配
RET        # 结束搜索，光标留在当前位置
C-g        # 取消搜索，回到搜索前的位置

替换

M-%        # 交互式替换（query-replace）
M-x replace-regexp  # 正则表达式替换

在交互式替换中，对每个匹配项可以：

SPC / y    # 替换并跳转到下一个
n          # 不替换，跳转到下一个
!          # 替换所有剩余的匹配
^          # 回到上一个匹配
RET        # 退出替换
C-r        # 进入递归编辑模式

窗口分割

Emacs 的"窗口"指的是缓冲区在屏幕上的显示区域，不同于操作系统的窗口概念。

C-x 2      # 水平分割窗口（上下）
C-x 3      # 垂直分割窗口（左右）
C-x o      # 切换到其他窗口（o = other）
C-x 0      # 关闭当前窗口
C-x 1      # 只保留当前窗口，关闭其他所有窗口
C-x ^      # 增加当前窗口高度
C-x }      # 增加当前窗口宽度
提示：可以在不同窗口中显示同一个文件的不同部分，这对于编辑长文档非常有用。

课程小结

本课涵盖了 Emacs 的核心操作。这些知识是学习 Org Mode 的基础。建议多练习这些快捷键，直到形成肌肉记忆。

关键要点回顾

  • 理解 C、M、S 的含义
  • 掌握文件操作：C-x C-f、C-x C-s、C-x C-c
  • 熟悉基本移动和编辑快捷键
  • 学会使用 C-g 取消操作
  • 善用帮助系统：C-h 前缀
