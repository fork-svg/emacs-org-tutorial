⚡ 第 15 课：代码块和 Babel

Org Babel 是 Org Mode 中最强大的功能之一，它让你在文档中嵌入、执行和导出代码。这使得 Org Mode 成为一个可执行文档系统——你的笔记、分析和代码可以在同一个文件中协同工作。

代码块语法

在 Org 文件中，代码块使用 BEGIN_SRC 和 END_SRC 标记：

#+BEGIN_SRC python
def hello():
    print("Hello, Org Babel!")
    return 42
#+END_SRC

也可以使用简写形式 #+begin_src（小写），效果相同。

创建代码块的快捷方式

在 Org 文件中按 C-c C-, s（即 org-insert-structure-template），然后选择 src，Emacs 会自动插入代码块框架。

在旧版 Emacs 中，使用 C-c C- 展开缩写模板。输入 <s 然后按 TAB 也可以快速插入代码块。

执行代码块

代码块可以在 Org 文件中直接执行。将光标放在代码块内部，按 C-c C-c，Emacs 会询问是否执行。

#+BEGIN_SRC python
result = 2 + 3
print(f"结果是：{result}")
#+END_SRC

#+RESULTS:
: 结果是：5

执行后，结果会插入到代码块后面的 #+RESULTS: 块中。

首次执行需要确认

出于安全考虑，Org Babel 默认在每次执行代码前询问确认。如果你信任你的 Org 文件，可以设置为自动执行： 
;; 设置为自动执行（不再每次询问）
(setq org-confirm-babel-evaluate nil)

;; 或者只对特定语言自动执行
(setq org-confirm-babel-evaluate
      (lambda (lang body)
        (not (member lang '("python" "emacs-lisp" "shell")))))

启用 Babel

Org Babel 需要显式启用语言支持：

;; 加载 org-babel
(org-babel-do-load-languages
 'org-babel-load-languages
 '((python . t)
   (emacs-lisp . t)
   (shell . t)
   (R . t)
   (sql . t)
   (sqlite . t)
   (js . t)
   (ruby . t)
   (perl . t)
   (C . t)
   (latex . t)
   (gnuplot . t)
   (plantuml . t)
   (dot . t)         ;; Graphviz
   (calc . t)
   (org . t)))       ;; Org 本身也可以执行！

语言示例

Emacs Lisp（内置，无需额外配置）

#+BEGIN_SRC emacs-lisp
(message "当前 Emacs 版本：%s" emacs-version)
(format "今天日期：%s" (format-time-string "%Y-%m-%d"))
#+END_SRC

#+RESULTS:
: 今天日期：2026-11-22

Shell 脚本

#+BEGIN_SRC shell :results output
echo "当前用户：$(whoami)"
echo "主机名：$(hostname)"
echo "当前目录：$(pwd)"
ls -la *.org | wc -l
#+END_SRC

#+RESULTS:
: 当前用户：scientist
: 主机名：myhost
: 当前目录：/home/scientist/org
: 5

R 语言（数据分析）

#+BEGIN_SRC R :results output
data <- c(1, 2, 3, 4, 5)
cat("均值：", mean(data), "\n")
cat("标准差：", sd(data), "\n")
cat("中位数：", median(data), "\n")
#+END_SRC

#+RESULTS:
: 均值： 3
: 标准差： 1.581139
: 中位数： 3

Python 数据处理

#+BEGIN_SRC python :results output
import json
from collections import Counter

text = "apple banana apple orange banana apple"
words = text.split()
counter = Counter(words)
for word, count in counter.most_common():
    print(f"{word}: {count}")
#+END_SRC

#+RESULTS:
: apple: 3
: banana: 2
: orange: 1

代码块参数

代码块可以接受多种参数来控制执行行为和结果处理。

结果类型（:results）

;; 结果输出方式
#+BEGIN_SRC python :results output
print("这是输出结果")
#+END_SRC

#+BEGIN_SRC python :results value
42  ;; 返回最后一个表达式的值
#+END_SRC

#+BEGIN_SRC python :results table
[[1, 2, 3], [4, 5, 6], [7, 8, 9]]
#+END_SRC

;; 结果插入方式
#+BEGIN_SRC python :results replace    ;; 替换已有结果（默认）
#+BEGIN_SRC python :results append     ;; 追加到已有结果后
#+BEGIN_SRC python :results silent     ;; 不插入结果

变量传递（:var）

;; 使用 Org 表格数据作为变量
| 姓名 | 年龄 | 城市 |
|------+------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
| 王五 | 28   | 广州 |

#+NAME: people
| 姓名 | 年龄 | 城市 |
|------+------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
| 王五 | 28   | 广州 |

#+BEGIN_SRC python :var data=people :results output
for row in data:
    print(f"{row[0]} 今年 {row[1]} 岁，来自 {row[2]}")
#+END_SRC

#+RESULTS:
: 张三 今年 25 岁，来自 北京
: 李四 今年 30 岁，来自 上海
: 王五 今年 28 岁，来自 广州

会话（:session）

使用 :session 参数可以让多个代码块共享同一个解释器会话：

#+BEGIN_SRC python :session mysession
import math
x = 10
#+END_SRC

#+BEGIN_SRC python :session mysession
y = math.sqrt(x)
print(f"√{x} = {y}")
#+END_SRC

#+RESULTS:
: √10 = 3.1622776601683795
:session 对于需要多次交互的场景特别有用，比如数据分析时需要在多个代码块中操作同一个 DataFrame，或者 R 语言中需要保持绘图状态。

命名代码块（:var 引用）

;; 命名代码块
#+NAME: square
#+BEGIN_SRC python :var x=5
return x * x
#+END_SRC

;; 调用命名代码块
#+BEGIN_SRC python :var result=square(x=7) :results output
print(f"7 的平方是 {result}")
#+END_SRC

#+RESULTS:
: 7 的平方是 49

Tangling 提取代码

Tangling 是将 Org 文件中的代码块提取为独立的源文件的过程。这在"文学编程"（Literate Programming）中非常有用。

基本 Tangle

;; 在代码块上添加 tangle 属性
#+BEGIN_SRC python :tangle hello.py
def greet(name):
    """问候函数"""
    print(f"你好，{name}！")

if __name__ == "__main__":
    greet("世界")
#+END_SRC

Tangle 操作

快捷键操作
C-c C-v t提取（tangle）当前文件的所有代码块
C-c C-v f提取并指定文件名
C-c C-v i插入（untangle）外部文件到代码块
;; 多个代码块提取到不同文件
#+BEGIN_SRC python :tangle main.py :tangle-mode (identity #o755)
#!/usr/bin/env python3
from utils import helper
helper.run()
#+END_SRC

#+BEGIN_SRC python :tangle utils.py
def helper():
    print("工具函数")
#+END_SRC

#+BEGIN_SRC bash :tangle install.sh :tangle-mode (identity #o755)
#!/bin/bash
pip install -r requirements.txt
python main.py
#+END_SRC
Tangle 是"文学编程"的核心功能。你可以把文档和代码写在同一个 Org 文件中，然后用 Tangling 提取出可运行的代码。代码的注释和文档就是你的 Org 文件正文。

实战示例：数据分析报告

以下是一个完整的数据分析示例，展示 Babel 的实用价值：

#+TITLE: 销售数据分析报告
#+PROPERTY: header-args:python :session analysis :results output

* 数据准备

#+NAME: sales-data
| 月份 | 产品A | 产品B | 产品C |
|------|-------|-------|-------|
| 1月  | 120   | 80    | 95    |
| 2月  | 135   | 90    | 100   |
| 3月  | 150   | 85    | 110   |
| 4月  | 140   | 95    | 120   |
| 5月  | 160   | 100   | 105   |
| 6月  | 175   | 110   | 130   |

* 数据加载

#+BEGIN_SRC python :var data=sales-data
import pandas as pd
df = pd.DataFrame(data[1:], columns=data[0])
print(df.head())
print(f"\n数据形状：{df.shape}")
#+END_SRC

* 统计分析

#+BEGIN_SRC python
# 各产品统计
stats = df.describe()
print("=== 描述性统计 ===")
print(stats)

# 相关性分析
numeric_df = df.select_dtypes(include='number')
print("\n=== 相关性矩阵 ===")
print(numeric_df.corr())
#+END_SRC

* 可视化

#+BEGIN_SRC python :results file
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei', 'Arial Unicode MS']

fig, ax = plt.subplots(figsize=(10, 6))
months = df['月份']
ax.plot(months, df['产品A'], 'o-', label='产品A', linewidth=2)
ax.plot(months, df['产品B'], 's-', label='产品B', linewidth=2)
ax.plot(months, df['产品C'], '^-', label='产品C', linewidth=2)
ax.set_title('月度销售趋势')
ax.set_xlabel('月份')
ax.set_ylabel('销售额（万元）')
ax.legend()
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('sales_trend.png', dpi=150)
'sales_trend.png'
#+END_SRC

#+RESULTS:
[[file:sales_trend.png]]

* 结论
根据分析：
1. 产品A 增长最稳定，6个月增长了约 46%
2. 产品B 和市场波动相关较大
3. 产品C 表现平稳，但增速低于产品A

配置最佳实践

;;; ========================
;;; Org Babel 推荐配置
;;; ========================

;; 启用语言支持
(org-babel-do-load-languages
 'org-babel-load-languages
 '((python . t)
   (emacs-lisp . t)
   (shell . t)
   (R . t)
   (sql . t)
   (dot . t)
   (plantuml . t)))

;; 设置执行确认
(setq org-confirm-babel-evaluate nil)

;; 代码块语法高亮
(setq org-src-fontify-natively t)

;; 保持代码块缩进
(setq org-src-preserve-indentation t)

;; 编辑代码块时使用原生模式
(setq org-edit-src-content-indentation 0)

;; 代码块窗口显示方式
(setq org-src-window-setup 'current-window)

;; 自动在代码块中开启对应 major mode
(add-hook 'org-babel-after-execute-hook 'org-display-inline-images)

;; 内联显示图片结果
(setq org-display-inline-images t)
(add-hook 'org-mode-hook 'org-toggle-inline-images)
设置 org-confirm-babel-evaluate 为 nil 有安全风险。只在你信任文件来源的情况下关闭确认。如果经常打开来自网络的 Org 文件，建议保持确认开启。

本课小结

本课你学习了 Org Babel 的核心功能：

  • 在 Org 文件中嵌入和编写代码
  • 使用 C-c C-c 执行代码块
  • 多种语言支持和会话管理
  • 代码块参数控制行为和结果
  • Tangling 提取可运行的源文件
  • 生成图表和数据分析报告
Org Babel 使 Emacs 成为一个"可复现研究"工具。你的文档、数据、分析和结论都在同一个文件中，任何人都可以重新执行你的代码来验证结果。这是科研和技术写作的强大工具。
