📥 第 13 课：捕获和附件

在本课中，你将学习 Org Mode 最强大的功能之一——Capture（捕获）。Capture 让你能在任何时刻快速记录想法、任务和笔记，而不打断当前工作流。同时，你还将学习如何管理附件文件。

什么是 Capture？

Capture 是 Org Mode 的快速记录系统。它的核心理念是：以最低摩擦捕获任何想法。无论你在 Emacs 中做什么，只需一个快捷键就能打开捕获模板，快速记录，然后回到原来的工作。

Capture 和 Agenda 是 Org Mode 的两大核心功能。Agenda 在第 12 课已经介绍，而 Capture 则是你每天使用最频繁的功能之一。

基本捕获流程

启动捕获的命令是 C-c c。按下后，Emacs 会提示你选择一个捕获模板。

第一步：配置 Capture 模板

在使用 Capture 之前，你需要在配置文件中定义至少一个模板。打开 ~/.emacs.d/init.el，添加以下配置：

;; 设置默认的捕获文件
(setq org-default-notes-file "~/org/notes.org")

;; 定义捕获模板
(setq org-capture-templates
      '(("t" "待办任务" entry (file "~/org/todo.org")
         "* TODO %?\n  %i\n  %a")
        ("n" "快速笔记" entry (file "~/org/notes.org")
         "* %?\n  %u\n  %i")
        ("j" "日记" entry (file+datetree "~/org/diary.org")
         "* %?\n  %U\n  %i")))
org-capture-templates 是一个列表，每个元素定义一个捕获模板。模板的第一个元素是快捷键（如 "t"），第二个是描述。

第二步：使用捕获

现在你可以在任何时候按 C-c c 开始捕获：

  1. 按 C-c c，迷你缓冲区显示模板列表
  2. 按 t 选择"待办任务"模板
  3. Emacs 打开一个新的捕获窗口，显示模板内容
  4. 在 %? 的位置（光标初始位置）输入任务内容
  5. 按 C-c C-c 完成捕获，内容保存到目标文件
  6. 如果想取消，按 C-c C-k

深入理解捕获模板

每个捕获模板由多个字段组成，我们来逐一解析：

;; 模板结构分解
(KEY DESCRIPTION TYPE TARGET TEMPLATE)

;; 示例：
("t"          ;; KEY - 快捷键
 "待办任务"    ;; DESCRIPTION - 描述
 entry        ;; TYPE - 条目类型
 (file "~/org/todo.org")  ;; TARGET - 目标位置
 "* TODO %?\n  %i\n  %a") ;; TEMPLATE - 模板文本

条目类型（Type）

类型说明用途
entryOrg 条目最常用的类型，创建一个标题
item列表项添加到 plain list
checkitem复选框项添加到 check list
table-line表格行添加到表格
plain纯文本插入纯文本到文件

目标位置（Target）

目标位置决定了捕获的内容存放在哪里：

;; 常用目标位置
(file "~/org/notes.org")          ;; 文件末尾
(file+headline "~/org/todo.org" "任务")  ;; 特定标题下
(file+olp "~/org/todo.org" "工作" "项目A")  ;; 多级路径
(file+datetree "~/org/diary.org")  ;; 日期树
(file+function "~/org/archive.org" my-func)  ;; 自定义函数

模板扩展（Template Expansions）

模板文本中可以使用多种 % 占位符：

占位符说明
%?光标初始位置
%t时间戳（日期，无时间）
%T时间戳（日期和时间）
%u非活跃时间戳（日期）
%U非活跃时间戳（日期和时间）
%i调用 Capture 时选中的文本
%a当前上下文的链接
%n当前用户名
%c当前 kill-ring 内容
组合使用这些占位符可以创建非常实用的模板。比如用 %i 和 %a 从网页或代码中快速摘录内容。

高级捕获模板

带选择的模板

你可以在模板中使用提示让用户选择：

(setq org-capture-templates
      '(("p" "项目任务" entry (file "~/org/projects.org")
         "* TODO %^{任务描述}\n  :PROPERTIES:\n  :项目: %^{项目名|工作|个人|学习}\n  :优先级: %^{优先级|A|B|C}\n  :END:\n  %?\n  %u")))

%^{prompt} 会在捕获时弹出提示让你输入值。%^{prompt|default1|default2} 形式提供默认选择。

带子模板的分组

你可以将模板分组，使菜单更清晰：

(setq org-capture-templates
      '(("t" "任务")  ;; 分组标题
        ("tt" "待办任务" entry (file "~/org/todo.org")
         "* TODO %?\n  %u")
        ("ts" "计划任务" entry (file "~/org/todo.org")
         "* TODO %?\n  SCHEDULED: %t")
        ("n" "笔记")  ;; 另一个分组
        ("nw" "工作笔记" entry (file+headline "~/org/notes.org" "工作")
         "* %? :work:\n  %U")
        ("np" "个人笔记" entry (file+headline "~/org/notes.org" "个人")
         "* %? :personal:\n  %U")))

从其他应用捕获

Capture 的强大之处还在于可以从外部调用：

;; 使用 emacsclient 从命令行捕获
emacsclient -c -a "" -e "(org-capture)"

;; 在 shell 脚本中快速记笔记
emacsclient -c -e '(org-capture nil "n")'

;; 使用 URL handler 从浏览器捕获
;; 需要配置 org-protocol
(setq org-protocol-protocol-alist
      '(("org-capture"
         :protocol "capture"
         :function org-protocol-capture
         :kill-client t)))
通过 org-protocol，你可以从浏览器、邮件客户端等外部应用直接发送内容到 Org Capture。这需要额外配置 emacsclient 作为后台服务。

附件管理

Org Mode 支持将文件（如图片、PDF、代码文件）作为附件关联到标题。

启用附件系统

;; 启用附件管理
(require 'org-attach)

;; 设置附件存储方式
(setq org-attach-id-dir "~/org/attach/")  ;; 附件存储目录
(setq org-attach-store-link-p 'attached)  ;; 存储时复制到附件目录

附件操作

在 Org 标题下，使用 C-c C-a 打开附件菜单：

快捷键操作
C-c C-a s存储附件（从文件选择器）
C-c C-a c从剪贴板粘贴附件
C-c C-a y拖放附件
C-c C-a o打开附件
C-c C-a f在文件管理器中显示附件目录
C-c C-a d删除附件
C-c C-a l列出所有附件

附件示例

附件存储结构如下：

;; Org 文件中的标题
* 项目设计文档
  :PROPERTIES:
  :ID:       a1b2c3d4-e5f6-7890-abcd-ef1234567890
  :END:
  附件已自动关联到此标题。

;; 物理文件结构
~/org/attach/
├── a1/b2c3d4-e5f6-7890-abcd-ef1234567890/
│   ├── 设计图.png
│   ├── 需求文档.pdf
│   └── 原型.sketch
附件 ID 使用 UUID 生成。确保 org-attach-id-dir 目录在版本控制中被正确处理（可以加入 .gitignore 或使用 Git LFS）。

在链接中引用附件

;; 链接到附件
[[attachment:设计图.png]]

;; 使用 ID 链接
[[id:a1b2c3d4-e5f6-7890-abcd-ef1234567890][项目设计文档]]

实用配置示例

以下是一个完整的、适合日常使用的 Capture 配置：

;;; ========================
;;; Capture 完整配置
;;; ========================

;; 默认笔记文件
(setq org-default-notes-file "~/org/inbox.org")

;; Capture 模板
(setq org-capture-templates
      '(("i" "收件箱" entry (file "~/org/inbox.org")
         "* %?\n  %U\n  %a")

        ("t" "任务")
        ("tt" "待办任务" entry (file+headline "~/org/todo.org" "收集箱")
         "* TODO %?\n  %U\n  %a")
        ("tp" "项目任务" entry (file+headline "~/org/projects.org" "任务")
         "* TODO %^{描述}\n  :PROPERTIES:\n  :项目: %^{项目}\n  :END:\n  SCHEDULED: %t\n  %a")

        ("n" "笔记")
        ("nn" "普通笔记" entry (file+datetree "~/org/notes.org")
         "* %?\n  %U\n  %i\n  %a")
        ("nw" "工作笔记" entry (file+headline "~/org/work-notes.org" "工作")
         "* %?\n  %U\n  :work:")

        ("m" "会议记录" entry (file+datetree "~/org/meetings.org")
         "* 会议：%?\n  与会者：\n  讨论：\n  行动项：\n  %U")

        ("j" "日记" entry (file+datetree "~/org/diary.org")
         "* %?\n  %U\n  心情：")

        ("r" "阅读" entry (file+datetree "~/org/reading.org")
         "* %^{标题}\n  作者：%^{作者}\n  %?\n  %u")))

;; 捕获完成后自动回到原窗口
(setq org-capture-bookmark nil)

;; 快捷键绑定
(global-set-key (kbd "C-c c") 'org-capture)
建议将 Capture 目标文件都集中在 ~/org/ 目录下，并将这些文件加入 org-agenda-files，这样所有捕获的内容都能在 Agenda 中看到。

本课小结

本课你学习了 Org Mode 的捕获系统和附件管理：

  • C-c c 启动 Capture，快速记录任何想法
  • 通过 org-capture-templates 定义自定义模板
  • 使用模板扩展（%?、%t、%a 等）自动化内容
  • 使用 org-attach 管理文件附件
  • 从外部应用（浏览器、命令行）调用 Capture
Capture 系统的最佳实践是：设置尽可能少的摩擦。模板越简单，你越容易养成随时记录的习惯。先用简单的模板开始，逐步根据需要添加复杂度。
