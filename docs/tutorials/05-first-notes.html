第 5 课：创建第一个笔记

从零开始创建你的第一个 Org 笔记文件

课程简介

现在你已经了解了 Org Mode 的基本概念，是时候动手创建你的第一个 Org 笔记了。本课将手把手教你创建一个完整的笔记文件，包括标题、内容、列表、链接等常用元素。

学习目标：完成本课后，你将能够独立创建和管理 Org 笔记文件，掌握常用的文本格式化方法。

创建 Org 文件

步骤一：创建目录

首先，建议创建一个专门的目录来存放 Org 文件：

# 在终端中创建目录
mkdir -p ~/org

# 或者在 Emacs 中按 M-! 执行命令
M-! mkdir -p ~/org RET

步骤二：创建新文件

  1. 在 Emacs 中按 C-x C-f（find-file）
  2. 输入文件路径：~/org/notes.org
  3. 按 RET 确认
  4. Emacs 会自动创建文件并进入 Org Mode
文件命名建议：使用描述性的文件名，如 work-notes.org、project-plan.org、reading-list.org 等。避免使用过于笼统的名称。

步骤三：验证 Org Mode

确认已进入 Org Mode：

  • 查看模式行（Emacs 底部），应显示 "Org" 字样
  • 或按 M-x describe-mode 查看当前模式
  • 如果未进入 Org Mode，按 M-x org-mode 手动切换

写第一个标题

Org Mode 使用星号（*）来创建标题。一个星号表示一级标题，两个星号表示二级标题，以此类推。

基本语法

* 一级标题
** 二级标题
*** 三级标题
**** 四级标题（最多支持 8 级，但建议不超过 4 级）

实战练习

在你的 notes.org 文件中输入以下内容：

* 学习笔记
** Emacs 基础
** Org Mode
** 快捷键总结

输入完成后，按 TAB 键在标题上可以折叠/展开子标题。按 S-TAB 可以全局折叠/展开。

标题规则：
  • 星号必须在行首
  • 星号后必须有一个空格
  • 标题可以嵌套，但建议层级不要太深
  • Org Mode 会自动为标题添加视觉缩进

添加内容

普通文本

在标题下直接输入文本即可：

* 学习笔记
** Emacs 基础
Emacs 是一个强大的文本编辑器，可以用来编写代码、
记笔记、管理任务等。

Org Mode 是 Emacs 的一个模式，用于组织信息和
管理待办事项。

列表

Org Mode 支持无序列表和有序列表：

* 购物清单
** 食物
- 苹果
- 牛奶
- 面包
- 鸡蛋

** 学习用品
1. 笔记本
2. 钢笔
3. 文件夹
4. 计算器

复选框

Org Mode 支持交互式复选框：

* 今日任务
- [X] 完成报告
- [ ] 回复邮件
- [ ] 整理文件
- [X] 参加会议

* 学习计划
- [ ] 阅读第一章
  - [X] 1.1 节
  - [ ] 1.2 节
  - [ ] 1.3 节
- [ ] 完成练习

按 C-c C-c 可以切换复选框状态。

提示：复选框非常适合用于任务清单。使用嵌套的复选框可以追踪子任务的完成情况。

文本格式化

Org Mode 支持多种文本格式化方式：

基本格式

*文字加粗*
/斜体/
_下划线_
+删除线+
=等宽字体=
~代码样式~

组合使用

*这是*加粗文字，/这是/斜体文字。
可以*组合使用*：*/加粗斜体/*，*_加粗下划线_*。

实战示例

* 笔记格式示例
** 重要概念
*Org Mode* 是一个强大的 /组织工具/。

** 代码示例
使用 =M-x org-mode= 命令切换到 Org Mode。
或者使用 ~org-mode~ 函数。

** 注意事项
+删除线+ 表示已删除的内容。
_下划线_ 用于强调。
注意：格式化标记两侧必须有非单词字符（如空格、标点符号），否则不会被识别。例如：*文字* 有效，但 *文字*abc 无效。

添加链接

Org Mode 支持多种类型的链接：

基本链接语法

[[链接地址]]
[[链接地址][显示文本]]

链接类型示例

* 链接示例
** 网页链接
访问 [[https://www.gnu.org/software/emacs/][Emacs 官网]]。
或访问 [[https://orgmode.org]]。

** 文件链接
打开 [[file:~/documents/report.pdf][报告文件]]。
查看 [[file:notes.org][笔记]]。

** 邮件链接
发送邮件给 [[mailto:test@example.com]]。

** 内部链接
参见 [[重要概念]] 部分。
或跳转到 [[*文本格式化]]。

在链接上操作

C-c C-o    # 打开光标下的链接
C-c l      # 存储链接（用于后续插入）
C-c C-l    # 插入存储的链接
提示：Org Mode 的链接功能非常强大。你可以链接到文件、网页、邮件、甚至其他 Org 文件中的特定位置。

创建表格

Org Mode 的表格功能是其亮点之一。表格使用 | 作为分隔符。

基本表格

* 数据表格
| 姓名 | 年龄 | 城市 |
|------+-------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
| 王五 | 28   | 广州 |

表格操作

Org Mode 会自动对齐表格列。输入时：

  • 按 TAB 会自动对齐并移动到下一个单元格
  • 按 S-TAB 移动到上一个单元格
  • 按 RET 会创建新行
  • 输入 |--- 后按 TAB 会插入水平分隔线

表格计算

* 成绩表
| 学生 | 数学 | 英语 | 总分 |
|------+------+-------+------|
| 张三 | 90  | 85   | 175 |
| 李四 | 88  | 92   | 180 |
| 王五 | 95  | 89   | 184 |
| 平均 | 91  | 88.7 | 179.7 |
#+TBLFM: @2$4=$2+$3::@3$4=$2+$3::@4$4=$2+$3
#+TBLFM: @5$2=vmean(@2..@4)::@5$3=vmean(@2..@4)::@5$4=vmean(@2..@4)
表格公式：按 C-c C-c 在 #+TBLFM 行上可以重新计算表格。Org Mode 支持丰富的公式语法。

添加标签

标签是组织信息的重要方式。Org Mode 支持在标题中添加标签。

基本标签语法

* 标题 :标签1:标签2:
** 工作计划 :work:
** 个人生活 :personal:
** 重要任务 :important:urgent:

添加标签的方法

  1. 手动在标题后输入 :标签:
  2. 使用快捷键 C-c C-q 交互式添加标签

预定义标签

在文件头定义可用标签：

#+TAGS: work(w) personal(p) important(i) urgent(u)

* 工作任务 :work:
标签搜索：使用 M-x org-tags-view 或 C-c a m 可以搜索带有特定标签的标题。

添加属性

属性是附加在标题上的键值对，用于存储结构化信息。

基本属性语法

* 项目任务
  :PROPERTIES:
  :ID: task-001
  :CATEGORY: work
  :EFFORT: 2:00
  :END:

  这是任务描述。

常用属性

* 任务示例
  :PROPERTIES:
  :CREATED: [2024-03-10 周日]
  :PRIORITY: high
  :STATUS: in-progress
  :END:

属性操作

C-c C-p    # 设置属性
C-c C-w    # 剪切标题（包括属性）
C-c M-w    # 复制标题（包括属性）

保存和管理

保存文件

C-x C-s    # 保存当前文件
C-x C-w    # 另存为
C-x s      # 保存所有修改的文件

文件管理建议

建议按用途组织 Org 文件：

~/org/
├── inbox.org        # 收件箱，快速记录
├── work.org         # 工作相关
├── personal.org     # 个人生活
├── projects.org     # 项目计划
├── notes.org        # 学习笔记
├── diary.org        # 日记
└── archive/         # 归档
    ├── 2023.org
    └── 2024.org

归档旧任务

C-c C-x C-a    # 归档当前标题
C-c C-x C-s    # 将当前标题移到归档文件
最佳实践：定期整理和归档完成的或不再相关的任务。保持主文件的简洁，有助于提高效率。
