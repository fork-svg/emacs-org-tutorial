🔗 第 17 课：与其他工具集成

Org Mode 的强大之处在于它的可扩展性。本课将介绍如何将 Org Mode 与你常用的工具集成——从 Git 版本控制到日历同步，从邮件管理到移动端访问。

Git 版本控制

将 Org 文件纳入 Git 版本控制是最佳实践，可以追踪修改历史、防止数据丢失。

基本设置

# 在 Org 目录初始化 Git 仓库
cd ~/org
git init
git add .
git commit -m "初始化 Org 仓库"

自动提交配置

;; 自动保存并提交 Org 文件
(defun my/org-auto-commit ()
  "自动提交 Org 文件修改到 Git"
  (when (string-match-p "\\.org$" (buffer-file-name))
    (let ((default-directory (expand-file-name "~/org")))
      (shell-command "git add *.org")
      (shell-command (format "git commit -m 'auto: %s'"
                             (format-time-string "%Y-%m-%d %H:%M"))))))

;; 在保存时自动提交
(add-hook 'after-save-hook 'my/org-auto-commit)

;; 或者使用 magit 手动管理（推荐）
;; 安装 magit
(use-package magit
  :bind (("C-x g" . magit-status)))

.gitignore 配置

# ~/org/.gitignore

# 自动生成的文件
*.html
*.pdf
*.aux
*.log
*.out

# 自动保存文件
*~
\#*\#
.\#*

# 附件目录（如果使用本地附件）
attach/

# 临时文件
*.tmp
*.bak

# 不跟踪敏感文件（如果有的话）
# secrets.org

自动同步到远程仓库

;; 使用 cron 或 magit 定时推送
;; 在 shell 中设置 cron
;; crontab -e
;; 0 */2 * * * cd ~/org && git add . && git commit -m "auto sync" && git push

;; 或者在 Emacs 中手动推送
;; M-x magit-status
;; 然后按 s (stage) c (commit) p (push)
推荐将 Org 仓库推送到私有 Git 仓库（GitHub、GitLab 或 Gitea），这样你可以在多台设备间同步，同时保持数据私密性。

日历集成

Org Mode 可以与系统日历双向同步。

导出为 iCalendar

;; 加载 iCalendar 模块
(require 'org-icalendar)

;; 配置导出选项
(setq org-icalendar-combined-agenda-file "~/org/my-calendar.ics")
(setq org-icalendar-include-todo t)         ;; 包含 TODO
(setq org-icalendar-use-deadline '(event-if-todo event-if-not-todo))
(setq org-icalendar-use-scheduled '(event-if-todo event-if-not-todo))
(setq org-icalendar-timezone "Asia/Shanghai")

;; 导出为 iCal
;; M-x org-icalendar-export-to-ics
;; M-x org-icalendar-export-agenda-files（批量导出）
;; M-x org-icalendar-combine-agenda-files（合并为单文件）

导入日历事件

;; 导入 iCal 文件到 Org
;; M-x org-import-calendar

;; 或者使用 org-caldav 实现双向同步（推荐）
(use-package org-caldav
  :config
  (setq org-caldav-url "https://caldav.example.com/calendars/")
  (setq org-caldav-calendar-id "personal")
  (setq org-caldav-inbox "~/org/calendar.org")
  (setq org-caldav-files '("~/org/todo.org"))
  (setq org-caldav-skip-conditions
        '(nottimestamp)))

;; 同步命令
;; M-x org-caldav-sync

与 Google Calendar 同步

;; 使用 Google Calendar API
;; 需要先在 Google Cloud Console 创建项目和凭据

(setq org-caldav-url "https://www.google.com/calendar/dav")
(setq org-caldav-calendar-id "your-email@gmail.com")
(setq org-caldav-inbox "~/org/gcal.org")

;; 同步 Google Calendar 的事件到 Org
;; 运行 M-x org-caldav-sync
org-caldav 支持与任何 CalDAV 服务器同步，包括 Nextcloud、Radicale、iCloud 等。这是实现跨设备日历同步最可靠的方式。

浏览器链接

通过 org-protocol 可以从浏览器快速捕获网页内容。

配置 org-protocol

;; 启用 org-protocol
(require 'org-protocol)

;; 确保 emacsclient 在运行
(server-start)

;; 配置 URL handler（需要在操作系统层面注册）
;; Linux: 创建 ~/.local/share/applications/org-protocol.desktop
;; [Desktop Entry]
;; Name=Org Protocol
;; Exec=emacsclient %u
;; Type=Application
;; Terminal=false
;; MimeType=x-scheme-handler/org-protocol

;; macOS: 使用 Platypus 或 Swift 创建 app
;; Windows: 注册表设置 URL handler

浏览器书签栏捕获

;; 在浏览器中添加书签栏按钮：
;; 名称：Org Capture
;; URL：javascript:location.href='org-protocol://capture?template=w&url='+
;;       encodeURIComponent(location.href)+'&title='+
;;       encodeURIComponent(document.title)+'&body='+
;;       encodeURIComponent(window.getSelection())

;; 对应的 Capture 模板
(setq org-capture-templates
      (append org-capture-templates
              '(("w" "网页摘录" entry (file+datetree "~/org/web-clips.org")
                 "* %:title\n  :PROPERTIES:\n  :URL: %:link\n  :END:\n  %:initial\n  %?\n  %U"))))

;; 也可以直接从浏览器创建 TODO
;; javascript:location.href='org-protocol://capture?template=t&url='+
;;   encodeURIComponent(location.href)+'&title='+encodeURIComponent(document.title)
浏览器捕获是建立"稍后阅读"系统的绝佳方式。看到感兴趣的文章，点击书签栏按钮，内容就会自动保存到 Org 文件中，附带原文标题和链接。

org-protocol 高级用法

;; 源引用（引用代码片段）
(setq org-capture-templates
      (append org-capture-templates
              '(("s" "源代码引用" entry (file+datetree "~/org/code-snippets.org")
                 "* %:title\n  :PROPERTIES:\n  :URL: %:link\n  :END:\n  #+BEGIN_SRC %:initial\n  %?\n  #+END_SRC\n  %U"))))

;; 使用 org-protocol 存储链接
;; 在浏览器中：
;; javascript:location.href='org-protocol://store-link?url='+
;;   encodeURIComponent(location.href)+'&title='+encodeURIComponent(document.title)

;; 4. 手机上使用 Orgzly 打开同步目录

;; WebDAV 方案
;; 在服务器上搭建 WebDAV
;; 使用 Cadaver 或 rclone 同步
;; rclone sync ~/org remote:org/

方案三：Termux + Emacs（Android 高级方案）

;; Android 上运行完整的 Emacs + Org Mode
;;
;; 1. 安装 Termux（从 F-Droid）
;; 2. pkg install emacs git
;; 3. git clone your-org-repo
;; 4. emacs ~/org/todo.org
;;
;; 优势：完整的 Emacs 体验
;; 劣势：需要命令行操作经验

;; 在 Termux 中的 Git 自动同步
;; ~/.bashrc 中添加
cd ~/org && git pull --rebase 2>/dev/null

;; 退出时自动提交
trap 'cd ~/org && git add . && git commit -m "mobile sync" && git push' EXIT

与通知系统集成

;; 使用 org-alert 提醒截止日期
(use-package org-alert
  :config
  (setq org-alert-interval 300)         ;; 检查间隔（秒）

(run-at-time "24:00" (* 24 3600) 'org-agenda-to-appt)  ;; 每天更新

与 Pomodoro 技术集成

;; 使用 org-pomodoro 番茄钟
(use-package org-pomodoro
  :after org-agenda
  :config
  (setq org-pomodoro-length 25)         ;; 工作时长 25 分钟
  (setq org-pomodoro-short-break-length 5)   ;; 短休息 5 分钟
  (setq org-pomodoro-long-break-length 15)   ;; 长休息 15 分钟
  (setq org-pomodoro-audio-player "aplay")   ;; 提示音播放器
  :bind
  (:map org-agenda-mode-map
        (("K" . org-pomodoro))))

;; 在 Agenda 中按 K 启动番茄钟
;; 番茄钟结束时会在 Org 文件中记录时间

自动化脚本

#!/bin/bash
# ~/org/sync.sh - 自动同步脚本

ORG_DIR="$HOME/org"
REMOTE="origin"
BRANCH="main"

cd "$ORG_DIR" || exit 1

# 拉取远程变更
git pull --rebase "$REMOTE" "$BRANCH"

# 添加所有变更
git add -A

# 提交变更（如果有）
if ! git diff --cached --quiet; then
    git commit -m "auto sync: $(date '+%Y-%m-%d %H:%M:%S')"
    git push "$REMOTE" "$BRANCH"
    echo "✓ 同步完成"
else
    echo "— 没有变更"
fi
自动同步脚本可能在多设备同时编辑时产生冲突。建议：1）使用 Git 的自动合并功能 2）冲突时手动解决 3）定期备份 Org 目录 4）考虑使用 Syncthing 代替 Git（Syncthing 的版本控制功能对 Org 文件更友好）。

完整集成配置示例

;;; ========================
;;; 工具集成完整配置
;;; ========================

;;; --- Git ---
(use-package magit
  :bind (("C-x g" . magit-status)))

;;; --- 日历 ---
(require 'org-icalendar)
(setq org-icalendar-combined-agenda-file "~/org/calendar.ics")
(setq org-icalendar-timezone "Asia/Shanghai")

;;; --- 提醒 ---
(use-package org-alert
  :config
  (org-alert-enable))

;;; --- 番茄钟 ---
(use-package org-pomodoro
  :after org-agenda
  :bind (:map org-agenda-mode-map ("K" . org-pomodoro)))

;;; --- org-protocol ---
(require 'org-protocol)

;;; --- 网页剪藏 ---
(setq org-capture-templates
      (append org-capture-templates
              '(("w" "网页剪藏" entry (file+datetree "~/org/web-clips.org")
                 "* %:title\n  :PROPERTIES:\n  :URL: %:link\n  :END:\n  %?\n  %U"))))

;;; --- 全局快捷键 ---
(global-set-key (kbd "C-c l") 'org-store-link)
(global-set-key (kbd "C-c c") 'org-capture)
(global-set-key (kbd "C-c a") 'org-agenda)

本课小结

本课你学习了 Org Mode 与各种工具的集成方案：

  • Git 版本控制保护你的数据安全
  • 日历集成实现跨设备同步
  • 邮件集成建立通信追踪
  • 浏览器链接实现快速剪藏
  • 移动端方案让你随时随地访问
  • 通知系统和番茄钟提升专注力
集成不是一次性完成的。先从最必要的集成开始（如 Git 版本控制和日历同步），然后根据需要逐步添加其他集成。每添加一个集成，花一周时间充分使用它，确保它确实提升了你的效率。
