第 1 课：安装 Emacs

在 Windows、macOS 和 Linux 上安装并验证 Emacs

课程简介

在开始使用 Org Mode 之前，我们需要先安装 GNU Emacs。本课将指导你在不同操作系统上完成 Emacs 的安装，并验证安装是否成功。

建议版本：本教程推荐使用 Emacs 28.x 或更高版本。Org Mode 已内置于 Emacs 中，无需单独安装。

Windows 安装方法

方法一：使用官方安装包（推荐）

  1. 访问 Emacs 官方下载页面：gnu.org/software/emacs
  2. 下载最新的 Windows 安装包（通常为 emacs-28.x-x86_64-installer.exe）
  3. 运行安装程序，按默认选项完成安装
  4. 安装完成后，可在开始菜单中找到 Emacs

方法二：使用 Scoop 包管理器

如果你已安装 Scoop，可以通过命令行快速安装：

scoop bucket add extras
scoop install emacs

方法三：使用 Chocolatey

choco install emacs
提示：Windows 用户也可以使用 WSL（Windows Subsystem for Linux）在 Linux 环境下安装 Emacs，这样可以获得更好的终端集成体验。

macOS 安装方法

方法一：使用 Homebrew（推荐）

Homebrew 是 macOS 上最流行的包管理器。打开终端后执行：

# 安装稳定版 Emacs
brew install emacs

# 安装带图形界面的版本
brew install emacs --cask

方法二：下载官方 DMG 镜像

  1. 访问 Emacs for macOS
  2. 下载 .dmg 镜像文件
  3. 打开镜像并将 Emacs 拖拽到「应用程序」文件夹

方法三：使用 MacPorts

sudo port install emacs
macOS 用户注意：推荐使用 Homebrew 安装，这样可以方便后续更新和管理。

Linux 安装方法

Ubuntu / Debian 系列

# 更新软件源
sudo apt update

# 安装 Emacs
sudo apt install emacs

Fedora / RHEL 系列

# 使用 DNF 安装
sudo dnf install emacs

Arch Linux 系列

# 使用 Pacman 安装
sudo pacman -S emacs

从源码编译（高级）

如果需要最新版本或自定义编译选项：

# 安装依赖
sudo apt install build-essential libgtk-3-dev libgnutls28-dev

# 下载源码
wget https://ftp.gnu.org/gnu/emacs/emacs-28.2.tar.gz
tar -xzf emacs-28.2.tar.gz
cd emacs-28.2

# 配置并编译
./configure --with-json --with-modules
make -j$(nproc)

# 安装
sudo make install
注意：从源码编译需要一定的时间，请确保系统已安装完整的编译工具链。

验证安装

安装完成后，需要验证 Emacs 是否正确安装。

在终端中检查版本

emacs --version

你应该看到类似以下的输出：

GNU Emacs 28.2
Copyright (C) 2023 Free Software Foundation, Inc.

启动图形界面验证

在终端中输入：

emacs

如果安装成功，你会看到 Emacs 的欢迎界面。界面上方显示菜单，中间是欢迎缓冲区。

提示：如果在终端中只想使用文本模式（无图形界面），可以使用 emacs -nw 命令启动。

首次启动

首次启动 Emacs 时，你会看到欢迎界面。以下是一些基本信息：

  • GNU 许可证：Emacs 是自由软件，遵循 GNU GPL 许可证
  • 帮助菜单：按 Ctrl+h 然后按 Ctrl+t 可以进入教程模式
  • 退出 Emacs：按 Ctrl+x 然后按 Ctrl+c（简写为 C-x C-c）

尝试基本操作

在 Emacs 中尝试以下操作：

  1. 打开一个新文件：按 C-x C-f，输入文件名后按回车
  2. 输入一些文字
  3. 保存文件：按 C-x C-s
  4. 关闭当前缓冲区：按 C-x k
术语说明：在 Emacs 中，Ctrl 键通常简写为 C，Alt（或 Meta）键简写为 M。后续教程将大量使用这些简写。

图形界面 vs 终端模式

Emacs 可以在图形界面（GUI）和终端（Terminal）中运行，各有优缺点：

特性 图形界面（GUI） 终端模式（Terminal）
鼠标支持 ✅ 完整支持 ⚠️ 有限支持
字体渲染 ✅ 高质量 ⚠️ 取决于终端
远程使用 ❌ 需要 X11 转发 ✅ 直接使用
启动速度 ⚠️ 稍慢 ✅ 较快
多平台 ⚠️ 依赖操作系统 ✅ 几乎任何终端
推荐：对于 Org Mode 初学者，建议使用图形界面版本，因为它提供更好的视觉反馈和鼠标操作支持。等熟悉后再尝试终端模式也不迟。

启动方式

# 图形界面启动（默认）
emacs

# 终端模式启动
emacs -nw

# 后台守护进程模式（适合长期使用）
emacs --daemon

# 连接到已运行的守护进程
emacsclient -nw    # 终端模式
emacsclient        # 图形界面模式

推荐的终端模拟器

如果你选择终端模式，以下是几个推荐的终端：

  • Linux：GNOME Terminal、Konsole、Alacritty、Kitty
  • macOS：iTerm2、Alacritty、Kitty
  • Windows：Windows Terminal、Alacritty

常见问题排查

问题：无法启动 Emacs

如果在终端中运行 emacs 命令无响应，请检查：

  • 确认 Emacs 已正确安装：运行 which emacs（Linux/macOS）或 where emacs（Windows）
  • 如果在远程服务器上使用，请尝试 emacs -nw（文本模式）
  • 检查是否有权限问题

问题：Windows 下中文显示乱码

如果遇到中文乱码问题，可以在 ~/.emacs 中添加：

(set-language-environment 'Chinese-GB)
(set-keyboard-coding-system 'utf-8)
(set-clipboard-coding-system 'utf-8)

问题：macOS 下 Emacs 无法找到 PATH 中的程序

某些图形界面启动的 Emacs 可能无法找到通过 Homebrew 安装的程序。可以尝试在配置中添加 PATH 设置，或从终端启动 Emacs。

课程小结

恭喜！你已经成功安装了 Emacs。在下一课中，你将学习 Emacs 的基本操作，包括键绑定、文件操作和缓冲区管理。这些基础知识对于后续学习 Org Mode 至关重要。

练习建议：在继续下一课之前，建议多花些时间熟悉 Emacs 的基本启动和退出操作。尝试用不同方式启动 Emacs，感受它的启动过程和界面布局。
