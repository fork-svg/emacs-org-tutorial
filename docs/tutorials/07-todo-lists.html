第 7 课：TODO 任务管理

Org Mode 最强大的功能之一就是内置的 TODO 任务管理系统。你可以用它来追踪待办事项、项目进度、日常工作任务等。本课将带你从零开始掌握 Org 的任务管理能力。

基本 TODO 标记

在 Org Mode 中，任何标题都可以变成 TODO 项。你只需要将光标移到标题行上，然后按下 C-c C-t。

* 待完成的任务
* 进行中的任务
* 已完成的任务

当你在标题上按 C-c C-t 时，标题会在以下状态之间循环切换：

* TODO 这是一个待办任务
* 另一个任务
* 还有一件事

再按一次 C-c C-t，状态变为 DONE：

* DONE 这个任务已完成

再按一次则回到无标记状态，再按一次又回到 TODO，如此循环。

你可以使用 C-c C-t 快速切换状态，也可以用数字快捷方式：1 到 9 在 TODO 快速选择界面中直接选择状态。

TODO 状态序列

默认的 TODO 和 DONE 两个状态可能不够用。你可以自定义状态序列来适应不同的工作流。在文件开头添加 #+TODO: 关键字来定义：

#+TODO: TODO(t) NEXT(n) WAITING(w) | DONE(d) CANCELED(c)

* TODO 需要做的事情
* NEXT 下一步就要做的
* WAITING 等待别人回复
* DONE 已经完成
* CANCELED 已取消

竖线 | 左边的是"未完成"状态，右边的是"已完成"状态。括号里的字母是快速快捷键，按 C-c C-t 后直接按对应字母即可切换到该状态。

你也可以在 Emacs 配置文件中全局定义状态序列，这样所有 Org 文件都会生效：

(setq org-todo-keywords '((sequence "TODO(t)" "NEXT(n)" "WAITING(w)" "|" "DONE(d)" "CANCELED(c)")))

多套状态序列

你可以定义多套平行的状态序列，用于不同类型的任务：

#+TODO: TODO(t) | DONE(d)
#+TODO: REPORT(r) BUG(b) KNOWNCAUSE(k) | FIXED(f)
#+TODO: | CANCELED(c)

* TODO 普通任务
* BUG 发现一个 bug
* FIXED 修复完成

每行定义一个独立的序列，任务状态只会在同一序列内切换。

快速任务和子任务

当一个标题的所有子任务都完成时，父标题可以自动标记为完成。这需要配置 org-hierarchical-todo-statistics。

* 项目 A  [0/3]
** TODO 子任务一
** TODO 子任务二
** TODO 子任务三

注意标题末尾的 [0/3]，这表示 0/3 个子任务已完成。当你完成一个子任务时，统计会自动更新：

* 项目 A  [1/3]
** DONE 子任务一
** TODO 子任务二
** TODO 子任务三
你也可以使用百分比显示进度：[33%]。在方括号内用 % 替换 / 前后的数字即可切换。

复选框统计

除了标题级别的子任务，Org 还支持在正文中使用复选框：

* 准备会议
  - [X] 预约会议室
  - [X] 发送会议邀请
  - [ ] 准备演示文稿
  - [ ] 打印材料

在复选框上按 C-c C-c 可以切换勾选状态。如果列表头部也有统计标记，复选框的变化也会自动更新统计：

* 准备会议  [2/4]
  - [X] 预约会议室
  - [X] 发送会议邀请
  - [ ] 准备演示文稿
  - [ ] 打印材料

嵌套统计

统计可以嵌套，形成多层进度追踪：

* 网站重构  [50%]
** TODO 前端  [75%]
*** DONE HTML 结构
*** DONE CSS 样式
*** TODO JavaScript 交互
*** DONE 响应式布局
** TODO 后端  [25%]
*** DONE 数据库设计
*** TODO API 开发
*** TODO 部署脚本

优先级设置

每个 TODO 项可以设置优先级，帮助你在众多任务中区分轻重缓急。

基本优先级

使用 C-c C-,（C-c 加逗号）来设置优先级。默认的优先级有三个：

  • #A — 最高优先级（重要且紧急）
  • #B — 中等优先级（默认）
  • #C — 最低优先级（不紧急）
* TODO [#A] 紧急修复线上 bug
* TODO [#B] 编写技术文档
* TODO [#C] 整理旧代码

按 C-c C-, 后再按 A、B 或 C 即可设置对应优先级。再按一次 C-c C-, 可以移除优先级。

自定义优先级范围

你可以自定义优先级的范围：

#+PRIORITIES: A C B

这行定义优先级从高到低为 A → C → B，其中默认优先级为 C。

优先级在议程视图中特别有用，它会影响任务的排序。高优先级的任务会排在前面。

实战练习

让我们创建一个完整的任务管理文件。打开一个新的 .org 文件，输入以下内容：

#+TODO: TODO(t) NEXT(n) IN_PROGRESS(i) WAITING(w) REVIEW(r) | DONE(d) CANCELED(c)

* 工作项目  [0%]
** TODO [#A] 完成季度报告
   DEADLINE: <2026-11-25 Wed>
   - [ ] 收集数据
   - [ ] 分析结果
   - [ ] 撰写报告
   - [ ] 提交审核

** NEXT [#B] 代码审查
   - [X] 查看 PR #101
   - [ ] 查看 PR #102
   - [ ] 写审查意见

** WAITING [#B] 等待客户反馈
   等待客户确认新的设计方案

* 个人事务
** TODO [#C] 学习 Org Mode
** DONE [#A] 买菜
** TODO [#B] 健身计划
记住，#+TODO: 行必须放在文件开头（标题之前），修改后需要按 C-c C-c 来刷新状态关键字。

常用命令速查

快捷键 功能
C-c C-t 循环切换 TODO 状态
C-c C-, 设置优先级
C-c C-v 查看 TODO 相关命令
M-S-RET 新建同级 TODO 项
C-c C-c 切换复选框状态 / 应用设置
S-LEFT / S-RIGHT 在 TODO 状态间快速切换

小结

本课我们学习了 Org Mode 的 TODO 任务管理系统，包括基本状态切换、自定义状态序列、复选框统计、优先级设置等内容。这些功能是 Org Mode 作为个人效率工具的核心，建议多加练习以形成肌肉记忆。
