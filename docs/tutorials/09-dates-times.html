第 9 课：日期和时间

日期和时间管理是 Org Mode 的另一项核心能力。通过时间戳（timestamp），你可以给任务设置截止日期、计划时间，记录工作时间，甚至创建重复任务。这些功能与议程视图（第 12 课）紧密结合，构成完整的日程管理系统。

时间戳基础

在 Org Mode 中，时间戳是尖括号包围的日期字符串：

<2026-11-22 Sun>           日期
<2026-11-22 Sun 14:00>      日期 + 时间
<2026-11-22 Sun 14:00-16:00> 时间段

插入时间戳

使用 C-c .（C-c 加句号）插入一个时间戳。Emacs 会弹出日期选择器：

  1. 将光标放在想要插入时间戳的位置
  2. 按 C-c .
  3. 在迷你缓冲区中编辑日期，或使用方向键导航日历
  4. 按 RET 确认

日期输入的快捷方式：

+3d       3 天后
+1w       1 周后
+2m       2 个月后
fri       下一个周五
tue       下一个周二
输入 C-c . 后，你可以直接输入相对日期表达式。例如输入 +0d 表示今天，+1d 表示明天，thu 表示下一个周四。

修改时间戳

将光标放在时间戳上，使用以下快捷键修改：

  • S-UP / S-DOWN — 增加/减少一天
  • S-RIGHT / S-LEFT — 增加/减少一天（替代方式）
  • C-c . — 重新编辑时间戳

截止日期（DEADLINE）

截止日期表示一个任务应该在此日期之前完成。使用 C-c C-d 设置：

* TODO 提交项目报告
  DEADLINE: <2026-11-25 Wed>
  还需要完善数据分析部分

截止日期会在议程视图中提前提醒你。默认提前 14 天开始提醒（可配置）。

截止日期的含义是"必须在此日期前完成"。适合有明确 deadline 的任务，如报告提交、会议准备等。

带时间的截止日期

截止日期也可以包含具体时间：

* TODO 参加线上会议
  DEADLINE: <2026-11-23 Mon 14:00>

重复截止

可以设置截止日期的重复间隔：

* TODO 提交周报
  DEADLINE: <2026-11-27 Fri +1w>

+1w 表示每周五重复一次。

计划时间（SCHEDULED）

计划时间表示你打算在什么时候开始处理这个任务。使用 C-c C-s 设置：

* TODO 开始写技术博客
  SCHEDULED: <2026-11-23 Mon>

与截止日期不同，计划时间不会提前提醒。它只在指定日期出现在议程视图中，表示"今天开始做这件事"。

注意区分 DEADLINE 和 SCHEDULED 的语义：
• DEADLINE：必须在此日期前完成（有紧迫感）
• SCHEDULED：计划在此日期开始处理（无紧迫感）
如果一个任务既有截止日期又有计划时间，可以同时设置两者。

同时使用截止和计划

* TODO 完成客户演示
  DEADLINE: <2026-11-28 Sat>
  SCHEDULED: <2026-11-24 Tue>
  需要提前准备幻灯片和演示数据

这表示你计划在 11 月 24 日开始准备，截止日期是 11 月 28 日。

重复任务

Org Mode 支持创建重复任务，非常适合日常例行工作。

基本重复任务

在时间戳中添加 +间隔 来定义重复：

* TODO 每日站会
  SCHEDULED: <2026-11-23 Mon 09:00 +1d>

* TODO 提交周报
  DEADLINE: <2026-11-27 Fri +1w>

* TODO 月度总结
  DEADLINE: <2026-11-30 Mon +1m>

重复间隔语法

表达式 含义
+1d 每天重复
+1w 每周重复
+2w 每两周重复
+1m 每月重复
+1y 每年重复
+2d 每隔一天重复

重复类型

Org 支持三种重复类型：

* TODO 每天检查邮箱
  DEADLINE: <2026-11-23 Mon +1d>
  ;; 标准重复：标记完成后，日期直接加 1 天

* TODO 检查服务器状态
  DEADLINE: <2026-11-23 Mon ++1d>
  ;; 累加重复：从上次日期加 1 天（跳过未完成的天）

* TODO 整理工作区
  DEADLINE: <2026-11-23 Mon .+1d>
  ;; 重新启动：从完成当天开始加 1 天
  • +1d（标准）：标记完成后，无论何时完成，新日期都是上次日期 + 1 天
  • ++1d（累加）：新日期是上次日期加上间隔的整数倍，保证不跳过
  • .+1d（重启）：新日期是完成时刻 + 间隔，适合"上次完成后 N 天再做"的任务
最常用的重复类型是标准重复（+1w）。只有当你需要精确控制"跳过间隔"或"从完成时间重新计算"时，才需要用到其他两种。

日记时间戳（Inactive Timestamp）

有时你只想记录一个事件发生的时间，而不需要它出现在议程中。使用方括号代替尖括号：

* 会议纪要
  创建于 [2026-11-20 Fri]
  参会人员：张三、李四、王五

* 代码审查
  审查日期 [2026-11-21 Sat 14:00]
  结论：需要重构数据库模块

使用 C-c ! 插入日记时间戳。它们不会出现在议程视图中。

工作时间记录（CLOCK）

Org 内置了工作时间记录功能，可以追踪你在每个任务上花费的时间。

开始和停止计时

将光标放在任务标题上，使用以下命令：

  • C-c C-x C-i — 开始计时（clock in）
  • C-c C-x C-o — 停止计时（clock out）
  • C-c C-x C-e — 手动编辑时间
* TODO 编写技术文档
  :LOGBOOK:
  CLOCK: [2026-11-22 Sun 09:00]--[2026-11-22 Sun 11:30] => 2:30
  CLOCK: [2026-11-22 Sun 14:00]--[2026-11-22 Sun 15:45] => 1:45
  :END:
计时记录存储在标题下方的 LOGBOOK 抽屉（drawer）中。你可以随时查看总共花费的时间。使用 C-c C-x C-d 可以显示当前文件的时间报告。

时间报告

使用 C-c C-x C-d 生成时间报告。Emacs 会在底部显示每个任务和总计的工作时间。

你也可以将时间报告插入文档：

* 项目工作日志

  #+BEGIN: clocktable :maxlevel 2 :scope file
  #+CAPTION: 工作时间汇总
  | Headline     | Time   |
  |--------------+--------|
  | *Total time* | *12:30*|
  |--------------+--------|
  | 编写文档     | 5:00   |
  | 代码审查     | 3:30   |
  | 会议         | 4:00   |
  #+END:

实战练习

创建一个包含各种日期时间的完整任务文件：

* 本周工作计划

** TODO 提交季度报告
   DEADLINE: <2026-11-27 Fri>
   SCHEDULED: <2026-11-23 Mon>
   - [ ] 汇总各组数据
   - [ ] 分析关键指标
   - [ ] 撰写总结部分

** TODO 参加项目评审会
   SCHEDULED: <2026-11-24 Tue 14:00>
   准备 15 分钟的 PPT

** TODO 每日站会
   SCHEDULED: <2026-11-23 Mon 09:00 +1d>

** TODO 整理代码仓库
   DEADLINE: <2026-11-27 Fri +1w>
   每周五清理过期的分支

* 会议记录

** 2026-11-20 项目启动会
   创建于 [2026-11-20 Fri]
   确定了项目时间线和技术方案

* 工作日志
** TODO 编写 API 文档
   :LOGBOOK:
   CLOCK: [2026-11-22 Sun 09:00]--[2026-11-22 Sun 12:00] => 3:00
   :END:

常用命令速查

快捷键 功能
C-c . 插入时间戳
C-c C-d 设置截止日期
C-c C-s 设置计划时间
C-c ! 插入日记时间戳
S-UP / S-DOWN 修改时间戳日期
C-c C-x C-i 开始计时（clock in）
C-c C-x C-o 停止计时（clock out）
C-c C-x C-d 显示时间报告
C-c C-x C-r 插入/刷新时间报告表格

小结

本课我们学习了 Org Mode 的日期和时间管理功能，包括时间戳、截止日期、计划时间、重复任务和工作时间记录。这些功能为第 12 课的议程视图打下基础——所有带有 DEADLINE 和 SCHEDULED 的任务都会自动出现在议程中。
