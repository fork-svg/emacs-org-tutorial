📤 第 14 课：导出和发布

Org Mode 不仅是一个笔记工具，它还是一个强大的文档编写系统。本课将教你如何将 Org 文件导出为 HTML、PDF、LaTeX、Markdown 等多种格式，以及如何配置发布项目来批量管理文档。

导出命令概览

所有导出操作都通过 C-c C-e 启动。按下后，Emacs 会显示一个导出菜单，列出所有可用的导出格式。

常用导出命令

快捷键序列操作
C-c C-e h h导出为 HTML 文件
C-c C-e h o导出为 HTML 并在浏览器中打开
C-c C-e l l导出为 LaTeX 文件
C-c C-e l p导出为 PDF（需要 LaTeX 环境）
C-c C-e l o导出为 PDF 并打开
C-c C-e m m导出为 Markdown
C-c C-e t t导出为纯文本
C-c C-e o o导出为 ODT（OpenDocument）
C-c C-e a a导出为 ASCII
每个导出格式都有两个快捷命令：第一个是导出到文件，第二个（以 o 结尾）是导出后直接打开。日常使用中，C-c C-e h o（HTML 导出并打开）是最常用的。

HTML 导出

HTML 导出是最常用的导出方式，适合发布网页、博客和文档。

基本 HTML 导出

创建一个示例 Org 文件 example.org：

#+TITLE: 我的第一个 Org 文档
#+AUTHOR: 张三
#+EMAIL: zhangsan@example.com
#+DATE: 2026-11-22
#+LANGUAGE: zh-CN

* 简介
这是一个使用 Org Mode 编写的文档。

** 特性
- 简洁的语法
- 强大的导出功能
- 支持代码高亮

* 安装
** 从源码安装
#+BEGIN_SRC bash
git clone https://github.com/example/project.git
cd project
make install
#+END_SRC

** 使用包管理器
#+BEGIN_SRC bash
sudo apt install myproject
#+END_SRC

按 C-c C-e h o，Org 会生成 HTML 文件并在浏览器中打开。

HTML 导出选项

通过文件头部的 #+OPTIONS 控制导出行为：

#+OPTIONS: toc:3          ;; 目录层级（3 表示显示到三级标题）
#+OPTIONS: num:t          ;; 标题编号
#+OPTIONS: <:t            ;; 导出时间戳
#+OPTIONS: \n:nil         ;; 不保留换行
#+OPTIONS: ::t            ;; 导出脚注
#+OPTIONS: f:t            ;; 导出脚注
#+OPTIONS: todo:t         ;; 导出 TODO 标记
#+OPTIONS: tags:t         ;; 导出标签
#+OPTIONS: H:3            ;; 最大标题层级
#+OPTIONS: html-style:embed  ;; 嵌入 CSS

自定义 HTML 样式

;; 使用自定义 CSS
(setq org-html-head-extra
      "")

;; 使用外部 CSS 文件
(setq org-html-head
      "")

;; 不生成默认的 HTML 头部
(setq org-html-head-include-default-style nil)

HTML 导出特殊标记

#+BEGIN_EXPORT html


  
这是原生 HTML，会直接嵌入到导出文件中。



#+END_EXPORT

@@html:这段文字会被高亮显示@@

LaTeX / PDF 导出

LaTeX 导出适合生成学术论文、技术报告等高质量排版文档。

基本配置

;; 设置 LaTeX 编译器
(setq org-latex-pdf-process
      '("xelatex -interaction nonstopmode %f"
        "bibtex %b"
        "xelatex -interaction nonstopmode %f"
        "xelatex -interaction nonstopmode %f"))

;; 默认使用 ctex 支持中文
(setq org-latex-default-packages-alist
      '(("AUTO" "inputenc" t ("pdflatex"))
        ("T1" "fontenc" t ("pdflatex"))
        ("" "graphicx" t)
        ("" "longtable" nil)
        ("" "wrapfig" nil)
        ("" "float" nil)
        ("" "textcomp" nil)
        ("" "markdown" nil)))

;; 添加中文支持
(add-to-list 'org-latex-packages-alist '("" "ctex"))
PDF 导出需要安装 LaTeX 发行版。推荐使用 TeX Live（Linux/macOS）或 MiKTeX（Windows）。中文 PDF 导出还需要安装 ctex 宏包。

LaTeX 文档选项

#+LATEX_HEADER: \usepackage{listings}
#+LATEX_HEADER: \usepackage{xcolor}

Markdown 导出

Markdown 导出适合与不支持 Org 格式的平台共享内容。

基本导出

;; Markdown 导出默认已包含在 Emacs 28+ 中
;; 如果没有，安装 ox-md
(require 'ox-md)

;; 导出为 Markdown
;; C-c C-e m m → 导出为 .md 文件
;; C-c C-e m b → 导出为 Markdown 并复制到剪贴板

Markdown 导出选项

;; 控制 Markdown 导出行为
(setq org-md-headline-style 'atx)       ;; 使用 # 风格标题
(setq org-md-toplevel-hlevel 2)         ;; 顶级标题从 ## 开始
(setq org-md-sub-superscript nil)       ;; 不导出上下标
Markdown 导出不支持所有 Org 特性。代码块、表格、链接等基本元素可以正常转换，但一些高级功能（如 Babel 执行、动态块）会被忽略或转换为静态文本。

其他导出格式

纯文本导出

;; C-c C-e t t → 导出为纯文本
(setq org-ascii-text-width 72)          ;; 文本宽度
(setq org-ascii-inner-margin 2)         ;; 内边距
(setq org-ascii-charset 'utf-8)         ;; 字符集

ODT 导出

;; C-c C-e o o → 导出为 ODT（可用 LibreOffice 打开）
;; ODT 导出需要安装 Open Office/LibreOffice
(setq org-odt-preferred-output-format "docx")  ;; 也可导出为 DOCX

发布项目

当你有多个 Org 文件需要一起发布（比如整个网站）时，发布项目功能可以批量处理。

基本发布配置

;; 加载发布模块
(require 'ox-publish)

;; 定义发布项目
(setq org-publish-project-alist
      '(;; 主要内容
        ("org-notes"
         :base-directory "~/org/content"
         :base-extension "org"
         :publishing-directory "~/public_html"
         :publishing-function org-html-publish-to-html
         :with-section-numbers nil
         :with-toc t
         :html-head ""
         :author "张三"
         :email "zhangsan@example.com")

        ;; 静态资源（图片等）
        ("org-static"
         :base-directory "~/org/content"
         :base-extension "css\\|js\\|png\\|jpg\\|gif\\|pdf"
         :publishing-directory "~/public_html"
         :publishing-function org-publish-attachment)

        ;; 完整项目（包含所有组件）
        ("website"
         :components ("org-notes" "org-static"))))

发布命令

快捷键序列操作
C-c C-e P x发布当前项目
C-c C-e P p发布当前文件所属项目
C-c C-e P f强制发布（忽略缓存）
C-c C-e P s发布所有项目
C-c C-e P t只发布最近修改的文件
发布系统会缓存已处理的文件，只重新发布修改过的文件。如果导出的文件显示旧内容，使用强制发布 C-c C-e P f 重新生成。

完整网站发布示例

;; 完整的个人网站发布配置
(setq org-publish-project-alist
      '(("org-site-main"
         :base-directory "~/org/site/"
         :recursive t
         :base-extension "org"
         :publishing-directory "~/org/public/"
         :publishing-function org-html-publish-to-html
         :html-head-include-default-style nil
         :html-head "
                     "
         :html-preamble "
首页 | 关于
"
         :html-postamble "

                            
作者：%a | 最后更新：%C

                            
由 Emacs Org Mode 生成

                          
"
         :auto-sitemap t
         :sitemap-filename "sitemap.org"
         :sitemap-title "网站地图"
         :sitemap-sort-files anti-chronologically)

        ("org-site-static"
         :base-directory "~/org/site/"
         :base-extension "css\\|js\\|png\\|jpg\\|gif"
         :publishing-directory "~/org/public/"
         :publishing-function org-publish-attachment)

        ("org-site"
         :components ("org-site-main" "org-site-static"))))

文件头导出选项速查

以下选项可以放在 Org 文件的头部：

#+TITLE: 文档标题
#+AUTHOR: 作者名
#+EMAIL: email@example.com
#+DATE: 2026-11-22
#+LANGUAGE: zh-CN
#+OPTIONS: toc:3 num:t <:t
#+EXPORT_FILE_NAME: output-name
#+EXPORT_SELECT_TAGS: export
#+EXPORT_EXCLUDE_TAGS: noexport
#+HTML_HEAD: <link rel="stylesheet" href="style.css">
#+HTML_LINK_HOME: https://example.com
#+LATEX_CLASS: article
#+LATEX_HEADER: \usepackage{ctex}
使用 :noexport: 标签可以排除特定标题不被导出。这在文件中有仅供个人参考的内容时非常有用。

  • HTML 导出适合网页发布
  • LaTeX/PDF 导出适合学术论文
  • Markdown 导出适合跨平台分享
  • 发布项目可以批量处理多个文件
  • 通过文件头和选项精细控制导出行为
