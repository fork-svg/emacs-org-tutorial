第 3 课：配置文件入门

学习 Emacs 配置文件结构，启用 Org Mode，构建推荐初始配置

课程简介

Emacs 的强大之处还在于其高度可定制性。通过配置文件，你可以让 Emacs 按照你的习惯工作。本课将介绍 Emacs 配置文件的基本结构和常用配置选项。

学习目标：理解 Emacs 配置文件的位置和语法，掌握基本配置方法，启用 Org Mode，并创建一个适合 Org Mode 的初始配置。

配置文件位置

Emacs 支持多个配置文件位置，推荐使用的是 ~/.emacs.d/init.el：

文件路径 说明 推荐程度
~/.emacs.d/init.el 现代推荐方式，便于管理 ⭐⭐⭐ 推荐
~/.emacs 传统方式，简单直接 ⭐⭐ 可用
~/.emacs.d/init.el (XDG) XDG 标准，适合整理 ⭐⭐ 可选
推荐做法：使用 ~/.emacs.d/init.el，因为 .emacs.d 目录可以存放额外的配置模块、包管理等文件，更易于组织和维护。

Lisp 基础语法

Emacs 使用 Emacs Lisp（elisp）作为配置语言。了解一些基础语法有助于理解配置：

注释

;; 这是单行注释
;; 通常使用两个分号表示行首注释

;; 多行注释使用 #| 和 |#
#| 这是
   多行注释 |#

设置变量

;; 设置变量值
(setq variable-name value)

;; 示例
(setq inhibit-startup-screen t)     ; 禁用启动界面
(setq make-backup-files nil)        ; 禁用备份文件
(setq auto-save-default t)          ; 启用自动保存

条件判断

;; if 语句
(if condition
    true-expression
  false-expression)

;; when 语句（只有 true 部分）
(when condition
  expression1
  expression2)

函数调用

;; Lisp 函数调用格式：(函数名 参数1 参数2 ...)
(add-hook 'org-mode-hook 'visual-line-mode)
(global-set-key (kbd "C-c c") 'org-capture)
学习建议：你不需要完全掌握 Lisp 语法。大多数时候只需要复制粘贴配置，理解每个配置项的作用即可。

启用 Org Mode

Org Mode 是 Emacs 的内置模式，默认已经安装。你只需要确保它正确启用：

基本启用

;; 确保 .org 文件使用 Org Mode
(add-to-list 'auto-mode-alist '("\\.org\\'" . org-mode))

启用 Org Mode 的常用功能

;; 启用 Org 的日程提醒
(add-hook 'org-mode-hook 'turn-on-org-indent)

;; 启用 Org 的自动换行
(add-hook 'org-mode-hook 'visual-line-mode)

;; 启用 Org 的表格对齐
(add-hook 'org-mode-hook 'org-indent-mode)
注意：Org Mode 已内置于 Emacs 22+ 版本，无需单独安装。如果你使用的是较新版本的 Emacs，Org Mode 应该已经可用。

基本配置选项

界面优化

;; 禁用启动界面
(setq inhibit-startup-screen t)

;; 禁用菜单栏（可选，看个人喜好）
(menu-bar-mode -1)

;; 显示行号
(global-display-line-numbers-mode 1)

;; 启用语法高亮
(global-font-lock-mode 1)

;; 显示括号匹配
(show-paren-mode 1)

;; 禁用工具栏（可选）
(tool-bar-mode -1)

;; 禁用滚动条（可选）
(scroll-bar-mode -1)

编辑行为优化

;; 启用自动缩进
(electric-indent-mode 1)

;; Tab 使用空格
(setq-default indent-tabs-mode nil)

;; 缩进宽度为 2 个空格
(setq-default tab-width 2)

;; 自动保存
(auto-save-mode 1)

;; 自动备份
(setq make-backup-files t)

;; 备份文件保存位置
(setq backup-directory-alist '(("." . "~/.emacs.d/backups")))

;; 自动保存文件位置
(setq auto-save-file-name-transforms
      '((".*" "~/.emacs.d/auto-save/" t)))

UTF-8 编码支持

;; 设置默认编码为 UTF-8
(prefer-coding-system 'utf-8)
(set-default-coding-systems 'utf-8)
(set-terminal-coding-system 'utf-8)
(set-keyboard-coding-system 'utf-8)

包管理器配置

Emacs 内置了包管理器，可以方便地安装和管理扩展。以下是基本配置：

;; 启用包管理器
(require 'package)

;; 添加 MELPA 源（Emacs 最大的第三方包仓库）
(add-to-list 'package-archives
             '("melpa" . "https://melpa.org/packages/") t)

;; 添加 MELPA Stable 源（稳定版本）
(add-to-list 'package-archives
             '("melpa-stable" . "https://stable.melpa.org/packages/") t)

;; 初始化包管理器
(package-initialize)

;; 刷新包列表（首次使用时需要执行）
;; 可以按 M-x package-refresh-contents 手动刷新

安装包的命令

;; 交互式安装包
;; 按 M-x package-install RET 包名 RET

;; 在配置中自动安装包
(unless (package-installed-p 'use-package)
  (package-install 'use-package))

;; 使用 use-package 管理包（推荐）
(require 'use-package)
(setq use-package-always-ensure t)
推荐：使用 use-package 可以让配置更整洁、更易管理。它会自动处理包的下载和加载。

推荐初始配置

以下是一个适合 Org Mode 初学者的完整配置文件模板。将以下内容复制到 ~/.emacs.d/init.el：

;;; ~/.emacs.d/init.el --- Emacs 配置文件 -*- lexical-binding: t; -*-

;;; 评论: 这是一个为 Org Mode 优化的初始配置

;; ====================
;; 基础设置
;; ====================

;; 禁用启动界面
(setq inhibit-startup-screen t)

;; 禁用欢迎界面
(setq inhibit-splash-screen t)

;; 禁用备份文件（避免产生 ~ 文件）
(setq make-backup-files nil)

;; 禁用自动保存
(setq auto-save-default nil)

;; 设置默认编码
(prefer-coding-system 'utf-8)
(set-default-coding-systems 'utf-8)

;; 显示行号
(global-display-line-numbers-mode 1)

;; 显示括号匹配
(show-paren-mode 1)

;; 设置 Tab 宽度
(setq-default tab-width 4)
(setq-default indent-tabs-mode nil)

;; ====================
;; 包管理器
;; ====================

(require 'package)
(add-to-list 'package-archives
             '("melpa" . "https://melpa.org/packages/") t)
(package-initialize)

;; 确保 use-package 已安装
(unless (package-installed-p 'use-package)
  (package-refresh-contents)
  (package-install 'use-package))

(require 'use-package)
(setq use-package-always-ensure t)

;; ====================
;; Org Mode 配置
;; ====================

;; 确保 .org 文件使用 Org Mode
(add-to-list 'auto-mode-alist '("\\.org\\'" . org-mode))

;; Org Mode 基本设置
(setq org-startup-indented t)        ; 启用视觉缩进
(setq org-startup-folded t)          ; 启动时折叠标题
(setq org-log-done t)                ; 完成任务时记录时间戳
(setq org-completion-use-ido t)      ; 使用 ido 补全

;; Org 快捷键
(global-set-key (kbd "C-c l") #'org-store-link)
(global-set-key (kbd "C-c c") #'org-capture)
(global-set-key (kbd "C-c a") #'org-agenda)

;; Org 自动换行
(add-hook 'org-mode-hook #'visual-line-mode)

;; Org 目录设置（后续会用到）
(setq org-directory "~/org")

;; ====================
;; 其他有用的设置
;; ====================

;; 启用 windmove（用 Shift+方向键切换窗口）
(when (fboundp 'windmove-default-keybindings)
  (windmove-default-keybindings))

;; 启用全局自动换行
(global-visual-line-mode 1)

;;; init.el 结束
说明：这个配置已经为 Org Mode 做好了基本准备。后续课程会逐步添加更多 Org Mode 特定的配置。

应用配置

创建或修改配置文件后，有几种方式让配置生效：

方法一：重启 Emacs

最简单的方法是重启 Emacs。退出后重新打开即可。

方法二：重新加载配置（不重启）

在 Emacs 中按 M-:（执行 Lisp 表达式），输入：

(load-file "~/.emacs.d/init.el")

或者使用 M-x eval-buffer（如果当前正在编辑配置文件）。

方法三：选择性执行

如果只想执行部分配置，可以选中代码后按 M-x eval-region。

注意：某些配置项（如包管理器的初始化）可能需要重启才能完全生效。如果遇到问题，可以尝试重启 Emacs。

验证配置

配置完成后，进行以下检查：

  1. 重启 Emacs，确认没有报错
  2. 按 C-x C-f 打开一个 .org 文件
  3. 确认进入 Org Mode（模式行显示 "Org"）
  4. 按 M-x describe-mode 查看当前模式信息
;; 如果遇到问题，可以查看 Emacs 消息日志
;; 按 C-x C 打开 *Messages* 缓冲区查看错误信息
