第 4 课：Org Mode 快速开始

了解 Org Mode 的核心概念，5 分钟快速体验

课程简介

Org Mode 是 Emacs 中最强大的模式之一。它可以用于笔记、待办事项管理、日程安排、项目规划、文档编写等多种用途。本课将介绍 Org Mode 的核心概念，并带你快速体验它的基本功能。

Org Mode 能做什么？
  • 结构化笔记和文档
  • 待办事项（Todo）管理
  • 日程安排和提醒
  • 项目管理
  • 表格和数据处理
  • 代码块和 Literate Programming
  • 导出为多种格式（HTML、PDF、Markdown 等）

核心概念

Org Mode 基于三个核心概念：大纲、任务和日程。

1. 大纲（Outline）

Org Mode 使用星号（*）来创建层级结构的大纲。这是 Org Mode 的基础：

* 一级标题
** 二级标题
*** 三级标题
**** 四级标题

这是标题下的内容。
可以有多个段落。

大纲可以折叠和展开，让你专注于当前关注的内容。

2. 任务（Todo）

在标题前添加 TODO 关键字，就可以将其标记为待办事项：

* TODO 完成报告
** TODO 收集数据
** TODO 撰写初稿
** DONE 发送审核    :COMPLETED:

任务状态可以在 TODO、DONE、CANCELLED 等之间切换。

3. 日程（Schedule）

Org Mode 可以为任务添加时间戳，并生成日程表：

* TODO 参加会议
  SCHEDULED: <2024-03-15 周五 14:00>

* TODO 提交报告
  DEADLINE: <2024-03-20 周三>
核心理念：Org Mode 的设计哲学是"纯文本、结构化、可操作"。所有数据都以纯文本形式存储，易于阅读和编辑，同时提供强大的组织功能。

5 分钟快速体验

让我们快速体验 Org Mode 的基本功能。按照以下步骤操作：

第一步：创建 Org 文件

  1. 在 Emacs 中按 C-x C-f
  2. 输入文件名（如 ~/test.org）并按回车
  3. Emacs 会自动进入 Org Mode
验证模式：查看 Emacs 底部的模式行，应该显示 "Org" 字样，表示当前处于 Org Mode。

第二步：创建大纲结构

输入以下内容：

* 工作计划
** 本周任务
*** TODO 完成项目报告
*** TODO 准备演示材料
*** 整理文件
** 下周计划
*** 团队会议
*** 项目评审

第三步：体验折叠功能

  1. 将光标放在 "* 工作计划" 这一行
  2. 按 TAB 键折叠子标题
  3. 再按 TAB 键展开
  4. 按 S-TAB（Shift+Tab）全局折叠/展开

第四步：添加任务状态

  1. 将光标放在 "** TODO 完成项目报告" 行
  2. 按 C-c C-t 切换任务状态
  3. 选择 DONE，你会看到状态变为 "DONE"
  4. Org Mode 会自动添加时间戳

第五步：添加时间戳

  1. 将光标放在某个标题下
  2. 按 C-c C-s（schedule）安排日程
  3. 使用日历选择日期，或使用快捷键
  4. 按回车确认
* TODO 参加会议
  SCHEDULED: <2024-03-15 周五 14:00>

这个任务已经被安排了日程。

第六步：保存文件

按 C-x C-s 保存文件。Org 文件就是普通的纯文本文件，可以用任何文本编辑器打开。

恭喜！你刚刚完成了 Org Mode 的基本操作。在后续课程中，你将深入学习每个功能。

Org 文件结构

一个典型的 Org 文件结构如下：

#+TITLE: 我的项目计划
#+AUTHOR: 张三
#+DATE: 2024-03-10
#+STARTUP: overview

* 项目概述
  这是项目的简介和背景说明。

* TODO 第一阶段：需求分析
  DEADLINE: <2024-03-20>
  ** TODO 收集用户需求
  ** TODO 编写需求文档
  ** DONE 需求评审

* 第二阶段：设计
  SCHEDULED: <2024-03-25>
  ** 架构设计
  ** 数据库设计
  ** 界面设计

* 第三阶段：开发
  ** 前端开发
  ** 后端开发
  ** 测试

* 备注
  重要联系人：
  - 项目经理：李四
  - 技术负责人：王五

# 文件末尾可以添加配置
# Local Variables:
# org-startup-folded: overview
# End:

文件头属性

Org 文件支持以 #+ 开头的文件头属性：

属性 说明 示例
TITLE 文档标题 #+TITLE: 我的笔记
AUTHOR 作者 #+AUTHOR: 张三
DATE 日期 #+DATE: 2024-03-10
STARTUP 启动选项 #+STARTUP: overview
TAGS 默认标签 #+TAGS: 工作 个人

日程视图简介

Org Mode 的日程视图是一个强大的功能，可以汇总所有 Org 文件中的任务和日程。

设置 Org 文件列表

首先，需要在配置中指定哪些文件参与日程：

;; 在 ~/.emacs.d/init.el 中添加
(setq org-agenda-files '("~/org/work.org"
                         "~/org/personal.org"))

打开日程视图

按 C-c a（如果已配置全局快捷键）或 M-x org-agenda，然后选择：

  • a：显示周视图（默认）
  • t：显示所有 TODO 项目
  • m：显示匹配的标签
  • s：搜索文本
说明：日程视图会从所有指定的 Org 文件中收集信息，并按时间或状态组织显示。这是 Org Mode 最强大的功能之一。

快速捕获简介

Org Capture 允许你快速记录想法、任务、笔记等，而不用离开当前工作。

配置 Capture 模板

;; 在 ~/.emacs.d/init.el 中添加
(setq org-capture-templates
      '(("t" "待办事项" entry (file "~/org/inbox.org")
         "* TODO %?\n  %i\n  %a")
        ("n" "笔记" entry (file "~/org/notes.org")
         "* %? :NOTE:\n  %U\n  %i\n  %a")
        ("j" "日记" entry (file+datetree "~/org/diary.org")
         "* %?\n  %U\n  %i")))

使用 Capture

  1. 按 C-c c（如果已配置全局快捷键）
  2. 选择模板（如按 t 表示待办事项）
  3. 在新缓冲区中输入内容
  4. 按 C-c C-c 确认并保存
  5. 或按 C-c C-k 取消
工作流程：将 Capture 作为你的"收件箱"，快速记录所有想法和任务，然后定期整理到相应的 Org 文件中。

导出功能简介

Org Mode 可以将文档导出为多种格式：

基本导出命令

C-c C-e    # 导出命令前缀

# 常用导出选项
C-c C-e h  # 导出为 HTML
C-c C-e l  # 导出为 LaTeX
C-c C-e p  # 导出为 PDF（通过 LaTeX）
C-c C-e m  # 导出为 Markdown
C-c C-e o  # 导出为 OpenDocument
C-c C-e t  # 导出为 Texinfo

导出选项

在文件头添加导出选项：

#+TITLE: 我的文档
#+OPTIONS: toc:t num:2
#+OPTIONS: H:3 ^:nil

* 第一章
...

* 第二章
...
提示：导出功能是 Org Mode 的强大特性之一。你可以用 Org Mode 编写文档，然后导出为漂亮的 HTML 网页或 PDF 文档。
